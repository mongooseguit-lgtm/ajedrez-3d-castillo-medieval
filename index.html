🐍 Cómo usar el Script en Blender (3.x / 4.x)

En la carpeta de este proyecto se ha generado el archivo blender_castillo_ajedrez.py.

1. Abre Blender y entra en la pestaña Scripting.
2. Haz clic en Open, selecciona blender_castillo_ajedrez.py y pulsa Run Script (▶).
3. El script modelará automáticamente el Gran Salón del Castillo, las columnas góticas, las antorchas con luces puntuales, el tablero biselado y las 32 piezas torneadas con materiales PBR.

También puedes ejecutarlo desde terminal para exportar castillo_ajedrez.glb:

blender --background --python blender_castillo_ajedrez.py
